# Mockups

Interactive mockups made in the design canvas, reacted to in conversation, then
used as the specification for a brief ("match this"). Each `.dc.html` is the
canvas artboard source (not a standalone page; it renders inside the canvas).

| File | What | Status |
| --- | --- | --- |
| `admin-page.dc.html` | Text admin page: shell (title, tags, lesson selector, text with pinyin edit mode) + tabs (Characters, Words in text, Expansions, Related words, Notes); four learner states; default filters | agreed 2026-10-25 |
| `dictionary-page.dc.html` | Dictionary page: counts, search and filters (kind, source, level, state, without a gloss), one row per entry with inline edit (HSK character: gloss; supplement: pinyin, gloss, level), the four states, add-an-entry with the supplement details form. One inaccuracy: HSK words have no Edit | agreed 2026-10-27, brief 13 |
| `import-text.dc.html` | Import-a-text form: title, author, period, tags, body; preview of the file it writes; import runs build and intake and opens the text | agreed 2026-10-27, brief 14 |
